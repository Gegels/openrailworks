# RailWorks / TSC formats (living document)

OpenRailWorks documents formats **from observation and tests** on legitimately owned installations.
No proprietary source code or leaked assets are copied into this repository.

## Status

| Area | Status |
|------|--------|
| Install layout (`Content/Routes`, `Packages`) | Documented via `orw-core` |
| `Tracks.bin` | Probe only (`orw-core::tracks`) |
| Blueprints / `.bin` vehicle definitions | Planned |
| `.ap` archives | ZIP (stored); read via `orw-vfs` |
| Lua vehicle/scenario API | Planned |

Contributions: describe on-disk layout, versioning, and parser behaviour in PRs.
